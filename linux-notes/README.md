# Linux Notes
### Linux Introduction

Today I started learning the basics of Linux and the terminal.

I learned some basic commands:
- `pwd` to check the current directory
- `ls` to list files and directories
- `cd` to change directories
- `cd ..` to go back to the parent directory
- `mkdir` to create a new directory
- `touch` to create a new file

I also learned the basic difference between files and directories, and practiced navigating through folders in the terminal.

### Linux Basic File Operations

Today I continued learning basic Linux commands and practiced file operations in the terminal.

I learned how to:
- create files with `touch`
- create directories with `mkdir`
- view file content with `cat`
- copy files and directories with `cp` and `cp -r`
- move or rename files with `mv`
- delete files and directories with `rm` and `rm -r`

Through practice, I became more familiar with how to manage files and folders in the terminal.

### Linux Paths and Terminal Basics

Today I continued learning Linux basics and became more familiar with paths in the terminal.

I learned the difference between absolute paths and relative paths, and practiced using `.` , `..` , and `~` to move between directories.

I also learned how command options work, such as `ls -l`, `ls -a`, and `ls -la`, and used `clear` to clean up the terminal screen.

Through these exercises, I developed a better understanding of how to navigate the file system more efficiently.

### Linux Wildcards and Command Options

Today I continued learning Linux basics and focused on command options and wildcards.

I learned how options such as `-l`, `-a`, and `-r` change the behavior of commands like `ls`, `cp`, and `rm`.

I also practiced using wildcards:
- `*` to match any number of characters
- `?` to match exactly one character

Through these exercises, I became more familiar with how to work with multiple files efficiently in the terminal.

### Linux Permissions and Process Basics

Today I learned the basics of Linux permissions and processes.

I used `ls -l` to view file permissions and understood the meaning of `r`, `w`, and `x` for files and directories. I also learned how to use `chmod` to change permissions, especially to make a shell script executable.

In addition, I learned the basic concept of a process as a running program. I practiced using `ps` to view processes and `top` to monitor running processes in real time.

Through these exercises, I gained a better understanding of how Linux controls file access and how running programs are managed in the system.
